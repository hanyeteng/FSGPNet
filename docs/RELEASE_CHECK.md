## 已修复的问题

1. **训练无法直接启动**：默认模型为 ADGFNet，且训练传入当前 `Net` 不接受的 `loss_name`。现统一为 FSGPNet 和 SoftIoU。
2. **学习率策略与论文不一致**：原默认使用 MultiStepLR。现默认 Adam / 0.001 / cosine annealing / 最小学习率 0.00001 / 400 epochs / batch size 8；仍可显式选择 MultiStepLR。
3. **数据路径参数未生效**：原训练和验证硬编码 `./datasets/...`。现所有入口均使用 `--dataset_dir`。
4. **设备选择不完整**：原评估和训练中的验证强制 `.cuda()`。现支持 auto、cpu、cuda、cuda:N；验证复用当前模型并正确恢复训练状态。
5. **CPU 上严格加载权重失败**：Gabor `meshgrid` 缓冲区为共享内存视图。现注册独立副本，保持键名、形状和数值兼容。
6. **批量测试参数错误**：原 `--model_names` / `--pth_dirs` 未配置列表解析，传入字符串可能逐字符循环。现使用 `nargs='+'` 并严格匹配数据集对应权重。
7. **可变尺寸测试批处理不正确**：旧代码只使用首张图片的原始尺寸和 Pd/Fa/F1。现明确只接受 batch size 1。
8. **评估阈值不一致**：nIoU 和 Pd/Fa 固定为 0.5，忽略用户阈值；F1 先按每张预测的最大值归一化。现所有指标直接使用相同绝对概率阈值。
9. **Fa 少计同面积假警**：原代码按面积数值排除匹配区域，另一个面积相同的假警会被一起排除。现按剩余未匹配连通区域计算。
10. **空掩膜处理**：F1 / Pd / Fa 的无目标或全零输入不再发生除零和无效归一化。
11. **续训状态不完整**：新训练权重保存优化器、调度器、随机状态和配置；仅加载兼容训练计划。旧权重没有这些状态时会警告近似续训。
12. **FP16 不稳定**：原 DCT/Gabor 路径在本次半精度检查中出现非有限损失。`--amp` 现明确警告并回退 FP32，不改动模型原有计算公式。
13. **掩膜中间灰度处理不一致**：IRSTD-1K 的 72 张训练掩膜和 13 张测试掩膜含中间灰度边界像素。原实现除以 255 后保留分数标签，指标使用不同取整规则。现训练和测试均以原始灰度 `>127.5` 二值化。原始 PNG 没有改写。

测试日志默认保存到 `log/`，图片、数据和训练缓存的 Git 规则已补齐。原有两份预训练权重没有重新训练或覆盖。
